# Benchmark guides

Start with the [module quick start](../README.md#quick-start) for setup, login
and a first run. Then choose the guide for your next step:

| Guide | What it explains |
|---|---|
| [configuration.md](configuration.md) | Model access, labels, setup, skills, rules and exclusions |
| [integrations.md](integrations.md) | MCP servers and CLI tools inside the sandbox |
| [python.md](python.md) | Each attempt's Python environment and dependency setup |
| [results.md](results.md) | Run files, task attempts, logs, diffs and scores |
| [pricing.md](pricing.md) | Estimate cost from saved usage and pricing policies |
| [publication.md](publication.md) | Validate and publish a run to a viewer |
| [credentials.md](credentials.md) | Inspect credential lifetimes and clean up private logins |
| [reference.md](reference.md) | Resume, retries, progress, storage and scoring details |

For files you can copy and customize, open the
[configuration and basket examples](../examples/README.md).
