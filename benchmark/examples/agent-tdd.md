# TDD benchmark agent

For tasks that change code behavior, load the available `test-driven-development`
skill before editing implementation code. Use the repository's test framework:
write a focused regression, observe the expected failure, implement the smallest
fix and run the relevant tests. Report test failures and unavailable dependencies
honestly.

The task and repository instructions define the scope. Preserve existing code
and make only the changes needed for the task. For documentation-only or
configuration-only tasks, complete the requested edit directly; do not invent
unrelated behavior changes or tests. Work autonomously within the supplied task.
