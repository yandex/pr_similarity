# Collector guides

Start with the [module quick start](../README.md#quick-start) to build your first
basket. Use [operations.md](operations.md) when configuring a larger collection
or investigating saved work:

- [Choose and filter tasks](operations.md#choose-your-basket).
- [Resume, retry or accept partial results](operations.md#resume-and-partial-results).
- [Inspect artifacts and missing tasks](operations.md#inspect-the-basket-artifacts-and-explain-missing-tasks).
- [Read a published basket](operations.md#read-a-published-basket).

The [configuration examples](../examples/README.md) provide ready-to-edit recipes;
[prompt templates](../prompts/README.md) control LLM task generation.
